# Glacier 预制体：ObscuredByClouds 适配版

预制体目录：`G:\My project\Unity_Play\Assets\Art\Ice\Prefabs`

本次从 `Glacier_Prefabs_New` 场景提取了 109 个模型预制体，新文件统一带 `_OBC` 后缀。原资源包、源场景和目标目录原有预制体未覆盖。

## 放置和绘制

在 Project 中搜索 `_OBC t:Prefab`，把需要的预制体加入你的模型绘制工具或直接拖入 `ObscuredByClouds`。使用模型绘制工具时，选择这些预制体资产作为笔刷对象。

保留原有模型结构、LOD、材质贴图、透明裁剪、树木风动及冰雪散射；清除资源展示场景的摆放位置、旋转和旧光照贴图索引。保留原碰撞体，原本没有碰撞体的模型补充静态网格碰撞体。

`Materials` 子目录存放 118 个独立材质，`Shaders` 子目录存放六类 Shader 适配及配套 include。移动或打包时需要保留这些依赖，以及项目已有的 SnowTracks 和 ObscuredByClouds/Lighting 脚本、Shader 文件。

## 昼夜与雪层

- 全部材质的 `Indirect Light Strength` 为 1，接入目标场景 `TimeOfDay` 的统一间接光倍率。太阳、月光、环境光继续使用场景现有设置。
- 有雪的材质使用匹配接口，模型根节点挂有 `TerrainSnowMaterialMatcher`。在地形的雪层上自动匹配颜色、法线、遮罩、平铺尺寸和偏移，编辑模式即可生效。
- 草地、离开地形、明显悬空的位置不启用地形雪层覆盖，恢复模型原有显示。原模型本来就雕刻或烘焙的雪帽仍会保留。
- 普通枝叶、树干等不含雪的材质保留原外观，只参与昼夜光照，不会被整株刷白。
- 混合区域选择主要雪层；真实生效的雪层与贴图看组件 Inspector，共享材质的原始贴图槽不随实例位置改写。
